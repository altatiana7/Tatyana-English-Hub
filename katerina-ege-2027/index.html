Выдача и проверка

Домашняя работа

Домашняя работа строится из трёх слоёв: core ФИПИ-задание, corrections по ошибкам и короткий input.

Core

Конкретное задание ФИПИ по текущему разделу.

Correction

Ошибка → правило → свой новый пример → retest.

Input

Чтение / аудирование / лексика по теме, без длинных списков слов.

После урока 2

Исправить 37, завершить 38.1 на 200–250 слов, выписать ошибки в формате «ошибка → правило → свой пример».
