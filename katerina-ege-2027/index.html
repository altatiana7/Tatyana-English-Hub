Рабочая система

Цель: стабильный высокий результат

Сначала фиксируем исходные результаты по всем разделам. Затем каждую неделю соединяем экзаменационный навык, языковую точность и развёрнутый ответ. Решения по нагрузке принимаем по данным, а не по впечатлению.
