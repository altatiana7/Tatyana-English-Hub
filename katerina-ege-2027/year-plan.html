Система курса

Цель: стабильный высокий результат, а не разовый удачный вариант

Курс строится по циклу: диагностировать → научить конкретному микроскиллу → выполнить задание ФИПИ под таймер → проверить по критериям → исправить ошибку → вернуться к ней через интервалы.

Урок A
Skill / accuracy

Разбор ошибок, чтение / аудирование / грамматика / лексика, точечная тренировка и короткий экзаменационный блок.

Урок B
Performance

Письмо 37/38 или говорение 1–4, работа по критериям, запись, self-check и новая домашняя цель.

Между уроками
2,5–4 часа

Официальные задания, исправления, запись устного ответа, повтор личных ошибок и мини-блок input.

Ориентир высокого уровня

Рабочий ориентир курса — выход в диапазон около 72+/82 первичных с дальнейшей стабилизацией, но индивидуальная цель фиксируется только после baseline. Точную шкалу перевода 2027 заранее не переносим механически.

Для преподавателя · что не показывать сразу

Не открывать ученице заранее ключи, ожидаемые ответы, критерии потери баллов, ваши выводы по слабым зонам, прогноз первичных баллов и список типичных ловушек конкретного задания. Это используется после первой попытки.

Первые 7–10 дней

Входная диагностика

Полный baseline нельзя заменить одним 60-минутным уроком. Обычный урок нужен для запуска и устной записи; письменную часть лучше вынести в отдельную сессию по времени.

Для преподавателя · диагностический протокол
  • Не показывать образцы 37/38 до первой попытки.
  • Для 37 фиксировать К1/К2/К3 и причину каждой потери.
  • Для 38 фиксировать К1–К5 отдельно: content, organisation, lexis, grammar, spelling/punctuation.
  • Для устной части сохранять первую запись как baseline.
  • После диагностики выбрать только 2–3 главных дефицита, а не «учить всё».

Для преподавателя · опасная ошибка курса

Не откладывать письмо и говорение до весны. В действующей модели письменная и устная части дают 40 из 82 первичных баллов, поэтому продуктивные навыки должны появляться практически каждую неделю.

  • Reading: устойчиво 10/12 без провала 12–18.
  • Grammar & Lexis: 15–16/18.
