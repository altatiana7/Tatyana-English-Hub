Система курса

Диагностика → навык → пробник

Курс строится по циклу: диагностировать → научить микроскиллу → выполнить задание ФИПИ под таймер → проверить по критериям → исправить ошибку → вернуться к ней через интервалы.

Урок A
Skill / accuracy

Разбор ошибок, чтение / аудирование / grammar & lexis, короткий экзаменационный блок.

Урок B
Performance

Writing 37/38 или Speaking 1–4, запись, self-check, критерии после первой попытки.

Между уроками
2,5–4 часа

ФИПИ-задания, corrections, запись устного ответа, повтор личных ошибок.

Для преподавателя · что не показывать сразу

Не открывать заранее ключи, ожидаемые ответы, критерии потери баллов, ваши выводы по слабым зонам и список ловушек конкретного задания. Это используется после первой попытки.

Первые 7–10 дней

Контроль

Тесты и KPI

Еженедельно

15–25 минут: один навык + 5–10 личных ошибок.

Каждые 4 недели

Sectional mock: L/R/G&L или Writing/Speaking по критериям.

Пробники

Недели 12, 20, 25, 29, 31, 33. Фиксировать первичные баллы, время, причины потерь.

Для преподавателя · KPI перехода
  • Reading: не меньше 80% с доказательством строкой текста.
  • Use of English: каждая ошибка записана как правило + свой пример.
  • 37: нет потери по коммуникативной задаче.
  • 38: есть сравнение + комментарий, проблема связана с темой, solution решает problem.
  • Speaking: запись укладывается во время, ответ полный, без длинных пауз.
Error Map

Система ошибок

Ошибка считается исправленной только после повторного применения в новом задании, а не после устного объяснения правила.

Категории

Listening evidence, reading inference, grammar form, word formation, collocation, register, organisation, task fulfilment, timing.

Интервалы

Возврат к ошибке через 1 день, 3 дня, 7 дней, 14 дней и в ближайшем mixed test.

Для преподавателя · правило переноса

Каждая повторяющаяся ошибка должна появиться в следующем уроке как mini-retest. Если ошибка повторяется 3 раза, она становится отдельной целью недели.

Последние 6–8 недель

Финальный этап

Недели 27–28

Закрытие крупных дефицитов, один полный пробник, точечная коррекция 37/38 и Speaking 3/4.

stabilise

Недели 29–31

Пробники, работа со временем, исправление только тех ошибок, которые реально стоят баллов.

mock cycle

Недели 32–34

Лёгкое смешанное повторение, финальные записи устной части, чек-листы, режим экзаменационного дня.
