Цель — не просто пройти формат, а выйти на управляемый высокий результат

Каждая неделя имеет два разных урока: урок А закрепляет точность языка и стратегию задания, урок Б переносит это в экзаменационный продукт: текст, устный ответ, чтение или аудирование по времени.

урок А
Language accuracy

Grammar, word formation, collocations, phrasal verbs, dependent prepositions, register, типичные ловушки 19–36.

урок Б
Exam performance

Для преподавателя · ключевая логика курса

Высокий балл требует не накопления заданий, а контроля причин потерь. После каждой проверки ошибка переносится в один из следующих трёх уроков: повтор правила, новый контекст, timed retrieval. Если ошибка повторилась дважды, она становится отдельной мини-целью недели.

Для преподавателя · интерпретация диагностики
  • 80%+ в receptive skills, но слабое writing/speaking: курс строится вокруг продуктивных критериев и language upgrade.
  • слабые 19–36: каждую неделю 25–30 минут системного Use of English + personal error deck.
  • слабое аудирование: обязательная evidence phrase после каждого ответа; не засчитывать «угадала».
  • 38 ниже ожидаемого: отдельно тренировать comparison/comment/problem/solution до полного текста.

Годовая траектория

письменная часть

Система Writing 37 и 38

37 · email

  1. Сначала только задача ФИПИ и таймер 20 минут.
  2. После сдачи — чек: 3 ответа, 3 вопроса, style, organisation, language.
  3. Преподаватель ставит К1–К3 и фиксирует причину потери.
  4. Через 48 часов — rewrite только проблемных частей, не всего текста по шаблону.

38 · project statement

  1. Отдельно тренируются facts, comparison, comment, problem, solution.
  2. Первые 6 недель — короткие фрагменты, затем полный timed text.
  3. Каждый текст проверяется по К1–К5.
  4. Повторная версия обязательна при провале логики или организации.
Для преподавателя · типовые критерийные риски
  • 37: формально есть 3 вопроса, но они не о новости из письма.
  • 37: ответы короткие, без раскрытия причины, из-за этого слабое содержание.
  • 38: цифры перечислены, но нет комментария к сравнению.
  • 38: problem и solution не связаны логически.
  • 38: conclusion не отвечает на opinion prompt.
устная часть

Система подготовки Speaking 1–4

Task 1

Чтение вслух: ударение, окончания, паузы, интонационные группы. Запись 1 раз в 2 недели.

Task 2

5 вопросов: грамматическая форма, прямой вопрос, точность к ситуации. Drill 5×40 секунд.

Task 3

Интервью: полный ответ, reason/example, отсутствие односложных ответов. Вопросы лучше давать аудио.

Task 4

Voice message: проектная тема, сравнение фото, личное мнение, conclusion. Запись по таймеру.

Feedback

После записи: 2 сильных места, 2 риска, 1 повторный дубль только проблемного ответа.

Bank

Темы: school, science, volunteering, technology, culture, travel, environment, jobs, education.

Для преподавателя · правило оценки устной части

Не исправлять всё сразу. В одной записи выбирается один главный фокус: полнота ответа, grammar accuracy, linking, pronunciation или task fulfilment. Следующая запись проверяет именно перенос этого исправления.

Для преподавателя · как принимать решение после теста

Если балл растёт, но одна категория ошибки повторяется, следующий месяц не расширяется, а сужается: 2–3 недели targeted repair. Если балл падает только из-за времени, вводится speed protocol: shorter blocks, strict timer, no post-answer rewriting during first attempt.

error log

Журнал ошибок и интервальное повторение

Категории

  • grammar form
  • word formation
  • collocation
  • phrasal verb
  • preposition
  • reading evidence
  • listening distractor
  • writing criterion
  • speaking timing

Формула записи

ошибка → правило → свой пример → новая проверка

Запись без нового примера не считается исправлением.

Интервалы

1 день → 3 дня → 7 дней → 14 дней → 30 дней. Повторная ошибка возвращает карточку на первый интервал.

Для преподавателя · перенос в урок

Каждый урок начинается с 5 минут retrieval по личным ошибкам. Каждая третья неделя содержит mixed block только из старых ошибок, но в новых контекстах.
