# Аудио урока Culture Shock

Файлов здесь нет до первого запуска озвучки — плеер в этом случае читает истории
браузерным синтезом речи (голос en-GB), а строка подсвечивается по ходу чтения.

Чтобы получить настоящий голос (как в `card-audio/`):

```bash
python3 -m venv .venv-tts
.venv-tts/bin/pip install edge-tts
.venv-tts/bin/python tools/culture-shock-tts.py
```

Скрипт сам разбирает `data.js`, пишет `ua.mp3`, `kr.mp3`, `de.mp3` и обновляет
`audio-manifest.js`. Повторно уже записанные файлы не перезаписываются.
Отдельные слова и диалоги читает браузерный синтез — файлы для них не нужны.

Ограничения: mono mp3, речь — держите файлы меньше 1 МБ. Обновлённый манифест
надо закоммитить вместе с mp3, иначе плеер не узнает о новой записи.
