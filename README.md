# Tatyana English Hub

Личный учебный хаб: материалы уроков и домашние задания учеников.
Планнер и оплаты живут локально на компьютере учителя — см. `docs/local-planner.md`.
Один статический сайт на GitHub Pages, без сборки и без бэкенда — каждая
страница открывается как обычный HTML-файл.

**Публикация:** https://altatiana7.github.io/Tatyana-English-Hub/

---

## Что внутри

| Папка | Что это |
|---|---|
| `index.html` | Корневая страница: уроки, домашка, список всех сайтов |
| `my-hub.html` | Список сайтов и курсов учеников |
| `my-lessons/`, `homework-hub/` | Разделы «Мои уроки» и «Домашка» |
| `ege-2027-b2-*`, `ege-teachers-hub` | Курсы ЕГЭ B2 (копии под разных учеников) |
| `spotlight-*`, `go-getter-*` | Материалы по школьным учебникам |
| `*-english-hub/`, `*-homework/` | Личные страницы учеников |
| `card-audio/` | Озвучка карточек (генерируется workflow, не редактируется руками) |
| `tools/` | Служебные скрипты и проверки |
| `_local/` (не в git) | Планнер для работы на компьютере, см. `docs/local-planner.md` |

## Как добавить страницу

1. Создайте папку с `index.html` в корне репозитория.
2. Добавьте ссылку в `my-hub.html` (и, если нужно, в `index.html`).
3. Пуши в `main` — сайт обновится автоматически.

Все пути **относительные** (`../styles.css`, `audio/track.mp3`): сайт живёт в
подкаталоге `/Tatyana-English-Hub/`, поэтому абсолютные пути от корня домена
(`/styles.css`) работать не будут.

## Приватность

Репозиторий **публичный**, поэтому:

* каждая HTML-страница содержит `<meta name="robots" content="noindex,nofollow">`;
* в корне лежит `robots.txt`, закрывающий индексирование целиком.

Это защита только от поисковых роботов. Любой, у кого есть ссылка, откроет
страницу. Не публикуйте здесь данные, которые нельзя показать посторонним
(адреса, суммы, переписку). Если это станет проблемой — переезд на приватный
хостинг (Cloudflare Pages / Netlify с паролем) описан в `docs/audit-2026-10.md`.

## Проверки

```bash
python3 tools/check-links.py          # битые локальные ссылки
python3 tools/check-links.py --strict # то же, но с exit 1 (используется в CI)
```

Проверка запускается автоматически на каждый push и pull request
(`.github/workflows/check-links.yml`).

## Медиа

Репозиторий тяжёлый: около 890 МБ, из них аудио и видео — почти всё.
GitHub Pages отдаёт сайт, собранный из рабочей копии, поэтому каждый мегабайт
здесь влияет и на скорость публикации, и на трафик учеников.

Правила:

* новое аудио — **mono 48–64 кбит/с**; этого достаточно для речи;
* длинные видео не храним в репозитории: выкладываем на YouTube (unlisted)
  и вставляем `<iframe>`;
* картинки — `.webp` до 1600 px по длинной стороне;
* `card-audio/` руками не чистим: имена файлов — это хеши текста карточек
  (`cyrb53` в `card-audio.js`), устаревшие файлы не определить «на глаз».

Для разового сжатия есть `tools/optimize-media.py` (нужен PyAV):

```bash
python3 -m venv .venv-media && .venv-media/bin/pip install av
.venv-media/bin/python tools/optimize-media.py --videos --dry-run
.venv-media/bin/python tools/optimize-media.py --videos
.venv-media/bin/python tools/optimize-media.py --audio
```

Скрипт подменяет файл только если новый вариант меньше на 10 % и больше,
а решения пишет в `tools/media-optimize-report.json`.

## Публикация

Деплой идёт через `.github/workflows/pages.yml` (GitHub Actions → Pages).
В настройках репозитория источник должен быть **GitHub Actions**, иначе
одновременно работают две схемы публикации и одна из них падает.

`.nojekyll` в корне обязателен: без него Jekyll-сборка спотыкается о файлы
с пробелами и квадратными скобками в именах.
