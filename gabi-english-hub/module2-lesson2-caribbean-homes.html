Comparison Gym

word in brackets

Quick rule

2 options: more spacious than / cheaper than
3+ options: the most suitable / the least practical
Equal: as spacious as / not as private as
Cause-effect: the closer..., the more...

Conditionals

transform the verb

Forms

Zero: If + present, present
First: If + present, will + V
Second: If + past, would + V
Third: If + had V3, would have V3
