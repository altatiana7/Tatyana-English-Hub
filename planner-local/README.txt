ПЛАННЕР — локальная версия
==========================

Здесь четыре файла. Работает только на этом компьютере, в интернет ничего
не отправляет: ни имён, ни оплат, ни заметок.

ЧТО ДЕЛАТЬ
----------

1. Скопируйте всю папку на компьютер, например в  Документы\Планнер.
   Важно: копировать целиком, все четыре файла рядом.

2. Двойной щелчок по  start-hub.bat.
   Откроется чёрное окно и браузер с планнером.
   Чёрное окно закрывать нельзя, пока работаете, — это и есть сервер.
   Закончили — закройте окно.

3. Первый раз нажмите в планнере кнопку  «В файл…»  и выберите файл
   planner-data.json  (например, там же, в папке Планнера).
   После этого каждое «Сохранить» записывается в этот файл само.

4. Один раз нажмите  «Копии…»  и выберите папку для дневных копий.
   Лучше — внутри облачного диска (OneDrive, Яндекс.Диск, Google Drive):
   тогда копии будут уходить с компьютера сами.
   Подробно и по шагам: docs/planner-backups.md в репозитории.

ЧТО КУДА ПИШЕТСЯ
----------------

  «В файл…»   рабочий файл planner-data.json — обычный текст, можно открыть
              блокнотом и прочитать.
  «Копии…»    раз в день отдельный файл planner-backup-ГГГГ-ММ-ДД.json.
              Существующий файл за сегодня не перезаписывается.
  Backup      скачать копию в «Загрузки» — запасной путь.
  Restore     прочитать копию обратно в планнер.

Выбранные файлы запоминаются в браузере, при следующем запуске ничего
выбирать заново не нужно.

ЧЕГО ЗДЕСЬ НЕТ
--------------

* Облака и синхронизации между компьютерами — намеренно: данные не покидают
  компьютер.
* Проверки кодов ЕГЭ — она обращалась к облаку и отключена. Результаты
  по-прежнему открываются у учеников на сайте.
* Учеников в настройках по умолчанию нет — список пустой, добавляйте своих
  на вкладке Students.

ЕСЛИ ЧТО-ТО НЕ ТАК
------------------

  «Порт 8765 занят»        планнер уже открыт в другом окне — закройте старое
  браузер открылся пустым  подождите 2-3 секунды и нажмите F5
  «Не удалось записать файл» нажмите «В файл…» и выберите файл заново
  антивирус ругается на .bat  разрешите запуск: файл только запускает
                             локальный сервер и открывает браузер
  данные пропали после чистки браузера — нажмите Restore и выберите
                             planner-data.json или свежую копию

ВАЖНО ПРО БРАУЗЕР
-----------------

Работает в Chrome и Edge. В Firefox кнопки «В файл…» и «Копии…» скажут, что
запись в файл недоступна, — там остаются «Сохранить» и Backup.

Не очищайте данные сайтов для 127.0.0.1, пока не убедились, что файл
planner-data.json на месте: в памяти браузера лежит вторая копия данных.
