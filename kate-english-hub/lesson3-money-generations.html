10. Conditionals Control Room

Rebuild the logic first: fact → real future → unreal now → unreal past → mixed time.

0 → 3 + MIXED

ZERO

Facts, routines, things that normally happen.
IF + Present Simple → Present Simple
If people spend more than they earn, they get into debt.

FIRST

A real or possible future result.
IF + Present Simple → WILL + V
If prices rise again, I’ll cut back on eating out.

SECOND

Imaginary / unlikely situation now or in the future.
IF + Past Simple → WOULD + V
If I had £10,000, I’d pay off my debt first.

THIRD

Imaginary past: the real past cannot be changed.
IF + had + V3 → WOULD HAVE + V3
If she had tracked her spending, she wouldn’t have overspent.

MIXED

Two times collide: past cause → present result, or present state → past result.
had + V3 → WOULD + V / Past Simple → WOULD HAVE + V3
If I had saved more last year, I wouldn’t be broke now.

12. Mixed Conditionals Time Machine

Decide which time causes which result. These are the ones people usually forget.

MIXED

1. If I had saved more last year, I ___ so stressed about money now.

Past cause → present result: had saved → wouldn’t be.

2. If she were more careful with money, she ___ that huge loan last year.

Present characteristic → past result: were → wouldn’t have taken.

3. If he hadn’t quit his side hustle, he ___ more disposable income now.

Past action → present situation: hadn’t quit → would have.

4. If I weren’t so impulsive, I ___ those trainers yesterday.

Present trait → past consequence: weren’t → wouldn’t have bought.

5. If they had avoided credit cards at university, they ___ so much money now.

Past cause → present result: had avoided → wouldn’t owe.

6. If Maya were better at budgeting, she ___ more before her trip.

Present ability/state → past consequence: were → would have saved.
