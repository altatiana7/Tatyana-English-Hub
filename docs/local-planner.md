# Планнер на вашем компьютере (Windows)

Планнер, оплаты и журнал больше не публикуются в интернете. Они живут в папке
на компьютере и открываются в один клик. Сайты учеников остаются на GitHub
Pages — там ничего не изменилось.

---

## Что лежит в папке `_local`

| Файл | Зачем |
|---|---|
| `start-hub.bat` | двойной клик — открывает планнер в браузере |
| `server.ps1` | маленький локальный сервер, запускается сам из `.bat` |
| `planner.html` | сам планнер (тот же, что был на сайте, плюс сохранение в файл) |
| `README.txt` | та же инструкция коротко, для папки |

Публикации нет: сервер отвечает только на этом компьютере по адресу
`http://127.0.0.1:8765/`, из интернета к нему не подключиться.

## Как пользоваться

1. Скопируйте папку `_local` на компьютер, например в `Документы\Планнер`.
2. Двойной щелчок по `start-hub.bat`.
3. Откроется браузер. **Чёрное окно закрывать нельзя**, пока работаете —
   это и есть сервер. Закончили — закройте окно.
4. Первый раз: нажмите в планнере **«В файл…»** и выберите
   `Документы\Планнер\planner-data.json`. После этого все изменения
   сохраняются в этот файл автоматически.
5. Один раз нажмите **«Копии…»** и выберите ту же папку — там каждый день
   будет появляться `planner-backup-2026-10-31.json`.

## Что происходит с данными

| Действие | Куда попадает |
|---|---|
| «Сохранить» в планнере | в память браузера **и** в выбранный файл |
| каждые 3 минуты | контрольная запись в файл, если были изменения |
| раз в день | отдельная копия `planner-backup-ГГГГ-ММ-ДД.json` |
| кнопка **Backup** | запасной вариант: файл в «Загрузки» |

Данные **не уходят в интернет**. Провайдер, GitHub и поисковики их не видят.

В локальной версии облачная синхронизация отключена намеренно:

* кнопка **Cloud** неактивна и подписана «Cloud выкл.»;
* функции отправки в Supabase вырезаны из кода — проверил тестом: при обычном
  сохранении сетевых запросов **ноль**, даже если в браузере остался старый
  облачный ключ от прежней версии;
* единственный запрос в сеть остаётся у вкладки *EGE Tests* — проверка кода
  результата (`ege-test-results`). Она отправляет только введённый код,
  без имён и оплат. Если не нужна — не пользуйтесь этой вкладкой.

## Восстановление

1. Откройте планнер (`start-hub.bat`).
2. Кнопка **Restore** → выберите `planner-backup-….json` или `planner-data.json`.
3. Появится «Восстановлено».

Если браузер почистили и планнер пустой — просто сделайте Restore из последнего
файла: данные в файле никуда не делись.

## Требования

* Windows 10 или 11 (PowerShell уже встроен);
* Chrome или Edge. В Firefox и старых браузерах кнопка «В файл…» скажет, что
  запись в файл недоступна — тогда работают «Сохранить» + **Backup**.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| «Не удалось занять порт 8765» | планнер уже открыт в другом окне — закройте старое |
| Браузер открылся, но страница пустая | подождите 2–3 секунды и обновите (F5) |
| «Файл не выбран» | нажмите «В файл…» один раз, дальше всё автоматически |
| Данные пропали после чистки браузера | **Restore** из файла в `Документах` |
| Антивирус ругается на `.bat` | разрешите запуск: файл только запускает локальный сервер |

## Обновления

Планнер теперь не обновляется сам — и это намеренно: никто снаружи не может
его изменить. Если понадобится новая версия, её нужно один раз заменить:
скопировать новый `planner.html` в папку, поверх старого. Данные в
`planner-data.json` при этом не трогаются.

## Чего здесь нет

Автоматического приёма ответов учеников. Пока планнер полностью локальный,
ответы приходят как раньше — через мессенджер. Если захотите, чтобы они
складывались сами, понадобится маленький облачный приёмник (Supabase):
писать в него сможет любой по ссылке, читать — только вы.
